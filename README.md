# Sentiment Analyser 🎬

A binary sentiment classification system that predicts whether a movie review is positive or negative using NLP and Machine Learning.

## Problem
Online platforms receive thousands of reviews daily. Manually reading each one to gauge customer sentiment is impossible at scale. This project automates that process.

## Solution
An NLP pipeline trained on 50,000 IMDB movie reviews using TF-IDF vectorisation and Logistic Regression classification.

## Results
- **Accuracy: 89.34%**
- Precision: 0.90 (Negative) | 0.88 (Positive)
- F1-Score: 0.89

## Tech Stack
- Python, scikit-learn, NLTK, pandas, matplotlib, seaborn

## Dataset
[IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
